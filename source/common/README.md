# Hợp đồng chung

`attempt.schema.json` mô tả response của REST attempt v1 theo định dạng độc lập ngôn ngữ. TypeScript DTO ở client và Java record ở server bám theo schema này. Giao thức realtime dự kiến và các destination được mô tả trong `PROTOCOL.md`; chưa có JSON schema cho sự kiện chưa triển khai.
